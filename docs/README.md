# Daily Ledger living documentation

This folder records decisions that should survive a handoff. Start with [architecture](architecture.md), then check the [data contract](data-contract.md) before changing persistence or import/export. Visual work follows [assets](assets.md); release work follows [quality](quality.md) and [deployment](deployment.md). Recurring upkeep is in [maintenance](maintenance.md).

The app is intentionally local-only. A feature that requires a backend is out of scope unless the product boundary is explicitly revised.
