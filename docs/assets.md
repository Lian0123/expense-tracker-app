# Asset integration

Generated assets live in `public/assets`. Each character state ships as AVIF and WebP with a transparent PNG fallback. All three formats are precached by the service worker so offline browsers can select their supported candidate. The source names are `hana-idle`, `hana-welcome`, `hana-input`, `hana-thinking`, `hana-income`, `hana-expense`, `hana-edit`, `hana-error`, `hana-empty`, `hana-import`, `hana-export`, and `hana-warning`. Their semantic mapping is in `characters/manifest.json` and `src/lib/assets.ts`.

Scene art uses the same AVIF/WebP/PNG set for `shrine-morning`, `shrine-noon`, `shrine-dusk`, `shrine-night`, and `shrine-late-night`. Scene mapping and fallback behavior are in `backgrounds/manifest.json`. Social art is `social/daily-ledger-og` in all three formats. Run `npm run assets:optimize` after changing a PNG source. Keep alpha edges intact, avoid adding a colored tile behind Hana, and never reference old anchor files in product UI.

The installable PWA identity is Hana's summer portrait in `brand/hana-app-icon-192.png` and `brand/hana-app-icon-512.png` (tracked in `brand/manifest.json`). AVIF and WebP siblings are provided for the in-app brand mark and favicon, while the manifest keeps PNG icons for broad install compatibility. These are deliberately opaque, high-contrast square icons with a generous safe area for Android/iOS masks. The source portrait was generated from `characters/hana-welcome.png` with the ImageGen logo-brand workflow and checked at both install sizes.

Mugi (麥麥柯基) is an optional, natural quadrupedal companion identity. Its transparent base is a short-legged, long-bodied corgi with a simple mint bandana; event aliases (`mugi-corgi.png`, `mugi-corgi-thinking.png`, `mugi-corgi-happy.png`) share this canine base while CSS choreography supplies movement. AVIF/WebP siblings and the complete mapping are recorded in `characters/manifest.json`. Mugi inherits the same hover interaction, mobile corner placement and bilingual dialogue; the PWA install icon intentionally remains Hana's stable brand mark.
