# Quality gates

`npm run quality` runs lint, formatting, strict typecheck, Jest coverage, documentation validation, SEO generation, production build, static SEO validation, and Playwright. Jest enforces global 85% branch and 90% function/line/statement coverage; the amount, repository, schema, and transfer modules each enforce 95%. Tests cover decimal arithmetic, schema rejection, IndexedDB CRUD and storage failure, merge/replace previews, CSV/JSON round trips, time boundaries, bilingual copy, mascot state classes, and category safety.

Playwright uses the production preview and verifies crawlable bilingual pages, IndexedDB persistence, exact amount sorting, second-level time entry and range filtering, custom categories, the seven-day spending projection, hover character interaction, the animated 320px mobile mascot, its four-corner persisted position, visible local clock, Hana PWA icons, GitHub Pages subpaths, and offline reopening. `npm run lighthouse` then checks the public landing pages and app entry. Public pages must score 90+ for Performance, Accessibility, Best Practices, and SEO; the private `/app/` shell is intentionally `noindex`, so its expected crawlability warning is explicitly validated instead of weakening the public SEO gate. Build first and provide `SITE_URL`/`BASE_PATH` when running the production suite locally.

Before release, test at 320/375/768/1024/1440px, keyboard-only flows, reduced-motion settings, an empty profile, multiple currencies, malformed imports, used-category deletion, offline reload, and a GitHub Pages subpath. Never lower a gate to hide a regression; document intentional threshold changes here.
